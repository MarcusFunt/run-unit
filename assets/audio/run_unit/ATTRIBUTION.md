# RUN//UNIT sound design sources

The files in this folder are edited/layered derivatives prepared for RUN//UNIT.

## Source packs

- **Kenney - Sci-fi Sounds** - CC0. https://kenney.nl/assets/sci-fi-sounds
- **Kenney - Interface Sounds** - CC0. https://kenney.nl/assets/interface-sounds
- **yd - Platformer Sounds: Terminal, Interaction, Door, Shots, Bang and Footsteps** - CC0. https://opengameart.org/content/platformer-sounds-terminal-interaction-door-shots-bang-and-footsteps

All source packs are licensed Creative Commons Zero (CC0), so attribution is not legally required. It is retained here for provenance.

## Processing

The game-ready OGG files were cut, level-balanced, filtered and, for several cues, layered with FFmpeg. The goal is a restrained industrial/sci-fi sound palette: short servo movement for jumping, weighted metal impacts, electrical damage, quiet machine-room ambience, positional hazard warnings, and unobtrusive UI feedback.
