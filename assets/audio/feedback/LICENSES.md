# Player feedback audio sources

These files are real recorded sound effects, not generated tones.

All five source files are by **BMacZero (Brian MacIntosh)** and are published
under **CC0 1.0** on OpenGameArt. Attribution is optional under CC0, but the
source is recorded here for provenance.

## Mechanical Sounds
Source: https://opengameart.org/content/mechanical-sounds  
License: CC0 1.0  
Original file used:
- `mechanical1.wav` -> `mechanical_action.wav`

## Metal Impact Sounds
Source: https://opengameart.org/content/metal-impact-sounds  
License: CC0 1.0  
Original files used:
- `clank1.wav` -> `metal_clank.wav`
- `clink1.wav` -> `metal_clink.wav`
- `thud2.wav` -> `body_thud_soft.wav`
- `thud3.wav` -> `body_thud_hard.wav`

The runtime layers these recordings at different volumes and slightly varied
pitch so jumps and impacts sound like a small machine instead of a retro
laser/explosion effect.
